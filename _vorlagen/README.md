# Grafik-Vorlagen

`ibb_grafik.py` erzeugt Balkengrafiken im Design von In-Berlin-Brandenburg.com
(Logo, Farben und Schriften aus `css-neu/main.css` der Seite).

- Farben: Primär-Rot #C5251B, Spreeblau #315C72, Beige #F4EFE5, Off-White #FAF7F1, Border #D6CFC0
- Schriften: Source Serif 4 (Überschrift, Lizenz: SIL Open Font License), Inter (Text)
- Formate: `feed` (1080 x 1350, Facebook/Instagram/X) und `pinterest` (1000 x 1500)
- Modi: `sequentiell` (eine Farbe, hell nach dunkel) und `divergierend` (Blau/Rot um einen Mittelwert)
